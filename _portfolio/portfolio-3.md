Developed an end-to-end pipeline for binary graph classification in Python based on a novel technique in topological data analysis (persistent reachability homology). 
Cleaned and processed epilepsy data using basic ETL pipeline. Applied pipeline to epilepsy classification task, with persistent reachability homology demonstrating superior performance to 
classical persistent homology. 

The code for the project can be found [here](https://github.com/njmead811/Persistent-Hochschild-Homology-Experiments-and-Applications/tree/main)).
An arxiv version of the paper can be found [here](https://arxiv.org/abs/2511.04825) and is currently submitted to a journal.
